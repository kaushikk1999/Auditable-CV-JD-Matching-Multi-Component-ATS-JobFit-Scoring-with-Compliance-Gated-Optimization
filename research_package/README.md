
# ATS CV Optimizer - Research Package

This package contains all artifacts needed to reproduce the ATS CV Optimizer results.

## Contents

- `benchmark/`: Directory for benchmark data files
- `benchmark_dataset_v1.json`: Synthetic CV-JD dataset for validation
- `experiments/`: Experiment run logs with scores and features
- `configs/`: Configuration files (weights, thresholds, word lists)
- `docs/`: Scoring equations and methodology
- `REPRODUCIBILITY_MANIFEST.json`: Environment and versioning details

## Dataset Information

> [!IMPORTANT]
> The dataset is **synthetically generated** by this project, NOT sourced from external platforms like Kaggle.

**Source:** In-house programmatic generation via `benchmark_dataset.py`  
**PII Status:** All names, emails, and contact information are fabricated (not real PII)  
**Current Size:** 1 CV-JD pair (expandable to 50+)  
**Domains:** Software Engineering, Data Science, Marketing, Healthcare, Education

## Reproducibility

1. Install dependencies: `pip install -r requirements.txt`
2. Load scoring config: `configs/scoring_config.yaml`
3. Run benchmark: `python scripts/benchmark_scoring.py`
4. Compare results with `experiments/benchmark_scores.csv`

# 🎓 ATS CV Optimizer

A state-of-the-art, 7-phase pipeline for optimizing CVs to achieve ≥95 ATS and Job-Compatibility scores.

## Features

✅ Multi-format CV ingestion (PDF, DOCX, TXT)
✅ JD parsing with keyword extraction
✅ Formal ATS + Job-Compatibility scoring
✅ AI-powered rewriting (Gemini)
✅ Compliance validation (stopwords, buzzwords, uniqueness)
✅ Multi-format export (PDF, DOCX, HTML, JSON)
✅ Research-ready reproducibility
